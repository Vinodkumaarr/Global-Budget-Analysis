# 🌍 Global Budget Analysis

An interactive **Government Budget Analytics Dashboard** built with **Python, Streamlit, MySQL, SQLAlchemy, Plotly, Pandas, and NumPy**. The application provides data-driven insights into historical government spending, sector-wise budget allocations, statistical anomalies, spending volatility, and predictive budget forecasting through interactive visualizations.

---

## 📌 Project Overview

Global Budget Analytics Core is a data analytics platform designed to analyze and visualize government budget data from multiple countries. It enables users to explore long-term financial trends, compare sector allocations, identify unusual fiscal patterns, and forecast future budget growth using statistical and analytical techniques.

The project demonstrates real-world applications of **Data Analytics**, **Business Intelligence**, **Data Visualization**, and **Predictive Analysis** using Python.

---

## 🚀 Features

### 📈 Historical Budget Analysis
- Analyze government budget trends over multiple years.
- Interactive line charts for expenditure growth.
- Country-wise filtering.

### 🥧 Sector Allocation Analysis
- Visualize budget distribution across sectors.
- Area Charts
- Box Plots
- Percentage-based allocation analysis.

### 🔍 Statistical Anomaly Detection
- Detect abnormal spending years using **Z-Score Analysis**.
- Highlight fiscal outliers.
- Interactive anomaly tables.

### 🔬 Research Lab
Includes advanced analytical modules such as:

- Cross-Sector Correlation Matrix
- Budget Volatility Index
- Rolling Mean & Standard Deviation
- Coefficient of Variation
- Interactive Heatmaps

### 📊 Budget Forecasting
- Polynomial Regression
- Multi-degree forecasting
- Scenario-based projections
- Adjustable economic shock simulation

# ⚙️ Installation

## 1 Clone Repository

```bash
git clone https://github.com/Vinodkumaarr/Global-Budget-Analysis.git
```

---

## 2 Navigate

```bash
cd Global-Budget-Analysis
```

---

## 3 Create Virtual Environment

Windows

```bash
python -m venv venv
venv\Scripts\activate
```

Linux / Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## 4 Install Dependencies

```bash
pip install -r requirements.txt
```

---

## 5 Configure MySQL Database

Create a MySQL database.

Example

```sql
CREATE DATABASE global_budget_db;
```

Import your SQL dataset.

Update your database credentials inside

```python
get_engine()
```

---

## 6 Run Application

```bash
streamlit run main_dashboard.py
```
